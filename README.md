# Portfolio de Lucca Silva Oliveira

Este é um portfólio ultramoderno, premium e visualmente impressionante para Lucca Silva Oliveira, construído com as mais recentes tecnologias de desenvolvimento web para criar uma experiência de usuário altamente interativa e cinematográfica.

## ✨ Recursos

- **Design Futurista**: Uma interface escura e elegante com detalhes em gradiente laranja que criam uma estética premium.
- **Animações Fluidas**: Transições de página e animações de componentes suaves, alimentadas pelo `Framer Motion`.
- **Fundo Interativo 3D**: Uma cena de fundo com partículas 3D que reagem dinamicamente ao movimento do mouse, criada com `Three.js`.
- **Efeitos de Hover 3D**: Cards de projeto que se inclinam e reagem à posição do cursor, proporcionando uma sensação tátil e interativa.
- **Transições de Página Cinematográficas**: Navegação entre a lista de projetos e os detalhes de um projeto com animações de layout compartilhado, criando uma experiência contínua e sem interrupções.
- **Totalmente Responsivo**: O layout se adapta perfeitamente a todos os tamanhos de tela, de desktops a dispositivos móveis.

## 🚀 Stack de Tecnologia

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Linguagem**: [TypeScript](https://www.typescriptlang.org/)
- **Estilização**: [Tailwind CSS](https://tailwindcss.com/) com componentes [ShadCN UI](https://ui.shadcn.com/)
- **Animações**: [Framer Motion](https://www.framer.com/motion/) e [GSAP](https://gsap.com/)
- **Gráficos 3D**: [Three.js](https://threejs.org/)
- **Inteligência Artificial**: [Genkit (Google AI)](https://firebase.google.com/docs/genkit)
- **Deployment**: Firebase App Hosting

## 🛠️ Como Começar

Para rodar este projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [URL_DO_REPOSITORIO]
    cd [NOME_DA_PASTA]
    ```

2.  **Instale as dependências:**
    ```bash
    npm install
    ```

3.  **Execute o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

Abra [http://localhost:9002](http://localhost:9002) no seu navegador para ver o resultado.
